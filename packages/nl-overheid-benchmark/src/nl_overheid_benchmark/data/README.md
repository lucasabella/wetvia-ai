# Conceptset v0

Deze vragen zijn een **concept**. `concept` staat op elk item op `true`. Een mens heeft ze nog niet afgevinkt. Issue #95 is die controle voor de toets, issue #92 voor de oefenstof. Een score op deze set is geen eindcijfer.

De zinnen en velden komen uit opgeslagen bronnen:

- Wetten: de officiële BWB-XML in `packages/nl-wetten-ingest/tests/fixtures/bwb_xml/` (CC0).
- Tweede Kamer: `herkomst/tk-documenten-2026-11-16.json`, open data, opgehaald op 16 november 2026 (CC0).
- Staatscourant: `herkomst/stcrt-2026-sample.xml`, SRU van officiële publicaties, opgehaald op 16 november 2026 (CC0).

De vraagzin eromheen is van dit project. Het juiste antwoord is een veld of een artikelnummer uit die bron, niet een bedachte wettekst.

De set valt onder CC BY 4.0. Zie [LICENSE-docs](../../../../../LICENSE-docs).

Elke vraag laat de brontekst meelezen. De meting kijkt of het model die tekst gebruikt. Het is geen examen uit het hoofd.
